# AI Sentinels Core (`ai-sentinels-core`)

Everyday AI for every staff member: plan your day, keep context, search across email, chat and documents, work with PDFs. Includes the AI Sentinels setup wizard, time-saved log and Copilot agents guide.

Part of the **AI Sentinels** workshop catalogue by AI Sentinels. Install only the packs your role needs; run `ai-sentinels-setup` from the Core pack for a recommendation.
