# Finance & Data (`ai-sentinels-finance-data`)

Finance and data: month-end close, reconciliations, variance analysis, audit support; explore spreadsheets and data, build charts and dashboards, check analysis before sharing.

Part of the **AI Sentinels** workshop catalogue by AI Sentinels. Install only the packs your role needs; run `ai-sentinels-setup` from the Core pack for a recommendation.

## Skills (18)

| Skill | What it does |
